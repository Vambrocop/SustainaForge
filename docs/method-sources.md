# Method Sources

SustainaForge is grounded in established sustainability-assessment practice rather than ad hoc prompting.

The first version is aligned with:

- ISO 14040 principles and framework for life cycle assessment;
- ISO 14044 requirements and guidelines for LCA studies and inventory studies;
- common process-systems and energy-systems TEA practice based on bottom-up cost models;
- scenario and sensitivity analysis as standard parts of credible process comparison;
- scale-up-aware interpretation for emerging technology papers.

This repository does not replace formal standards or detailed engineering models. It helps an AI agent keep the right questions visible while humans and deterministic code own the final calculations and claims.
